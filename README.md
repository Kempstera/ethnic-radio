# 华韵集 · 中国少数民族广播电台

一个单页（SPA）的中国少数民族语言广播电台聚合播放器。

线上地址：**https://ethnic.signupeverywhere.cc/**

## 这是什么

页面加载时从开放电台数据库 [Radio-Browser.info](https://www.radio-browser.info/)
拉取中国的全部电台，在前端按民族语言关键词筛选、去重、剔除无效源，然后以毛玻璃卡片
网格呈现。点击任意卡片，底部悬浮播放器立刻加载并播放该电台的直播流。

## 技术栈

- 纯 **HTML + CSS + 原生 JavaScript**，零框架、零构建
- **hls.js** 处理 `.m3u8` 直播流（本地副本 + jsDelivr CDN 自动回退）
- **FontAwesome** CDN 图标
- 全部代码在单个 `index.html` 内

## 播放兼容性

| 场景 | 处理方式 |
|---|---|
| `https://` + `.m3u8` | hls.js 解析播放，失败自动降级原生 HLS（Safari） |
| `https://` + `.mp3` / `.aac` | 原生 `<audio>` 直接播放 |
| `http://` 源 | 依次尝试：https 升级 → 公共 CORS 代理 → 原地址 |

同名电台的多条线路（不同码率 / 不同 CDN）会自动合并去重，优先保留 HTTPS 与高码率线路。
播放失败时按线路顺序自动重试，全部失败才弹出友好提示。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用（结构 + 样式 + 逻辑） |
| `hls.min.js` | hls.js 本地副本；加载失败自动回退 CDN |
| `wrangler.toml` | Cloudflare Pages 项目配置 |

## 部署

Cloudflare Pages，零构建直接发布本目录：

```bash
npx wrangler pages deploy . --project-name ethnic-radio
```

## 本地预览

```bash
python3 -m http.server 4180
# 打开 http://127.0.0.1:4180/
```

## 其他

- 音量、上次收听的电台记忆在 `localStorage`
- 空格键播放 / 暂停
- 音频流由各电台官方 CDN 直供，本站不存储、不转播任何音频内容
